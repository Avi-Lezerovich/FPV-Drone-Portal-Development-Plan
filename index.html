CHAPTER 05 // SCHEMATICS & PINOUTS

Wiring Diagrams & UART Mapping

Interactive inline SVG schematics for both rigs. Study the three non-negotiable electrical rules below before plugging in your DJI O4 Air Unit Pro or heating your soldering iron.

⚡ RULE 01 // O4 PRO POWER (7.4V–26.4V ONLY)

The DJI O4 Air Unit Pro requires 2S–6S (7.4V to 26.4V). Always power it from your FC's dedicated 9V / 10V DJI BEC rail or directly from VBAT. NEVER wire O4 Pro power to a 5V pad—it will brown out and reboot mid-flight when RF output spikes.

✂️ RULE 02 // DROP THE DJI SBUS WIRE FOR ELRS

The 6-pin DJI JST-SH harness includes a Yellow (DJI HDL / SBUS RX) wire on Pin 5/6 (typically routed to FC UART2 RX). Because you are flying ExpressLRS, gently lift the plastic tab on the JST plug with a hobby blade and remove/insulate the SBUS wire so UART2 stays free or avoids conflicting with your ELRS receiver!

💡 RULE 03 // 5V WS2812B LEDs & TX↔RX CROSSOVER

Every UART peripheral (ELRS, O4 Pro MSP, GPS) crosses over: Peripheral TX → FC RX and Peripheral RX → FC TX. For the Cinelog30 V3 dusk LEDs, only use 5V addressable WS2812B strips wired to 5V, GND, and the FC LED data pad (arrow pointing away from solder pad).

CHAPTER 07 // FLIGHT CONTROLLER CONFIGURATION

Software Part 1: Betaflight 4.5+ Core Setup

Configure both the 5" 6S Velox F7 SE and the 3" 4S Cinelog30 V3 TAKER F722 AIO using Betaflight Configurator (Web / Desktop) ↗. Always remove all propellers before connecting a LiPo on the bench.

STEP 01 // BACKUP & PORTS TAB BOTH DRONES

1. Factory Diff Backup & UART Mapping

Before changing any setting (especially on the factory-tuned Cinelog30 V3), open the CLI tab, type diff all, and click Save to File. Then configure the Ports tab and click Save and Reboot:

  • UART 1 (DJI O4 Air Unit Pro) MSP ON + Peripherals: VTX (MSP + Displayport)
  • UART 2 (ELRS 2.4GHz RX) Serial Rx = ON (All others OFF)
  • UART 3 (5" M10 GPS Module) Sensor Input: GPS @ 115200 Baud
  • UART 4 (ESC Telemetry Line) Sensor Input: ESC (Optional w/ Bi-Dir DShot)
🛠️ Guide: Oscar Liang Betaflight Setup 📘 Tool: Betaflight Web Configurator
STEP 02 // RECEIVER & SYSTEM CONFIG CRSF + AETR1234

2. Receiver Tab (ELRS CRSF) & System Features

In the Configuration and Receiver tabs, configure the flight controller to communicate with your RadioMaster TX15 Max / Boxer ELRS radio:

  • Receiver Mode / Provider Serial (via UART) // CRSF
  • Channel Map (EdgeTX Default) AETR1234 (Roll, Pitch, Thr, Yaw)
  • Telemetry & OSD Toggles TELEMETRY = ON // OSD = ON
  • Cinelog30 V3 LED Feature LED_STRIP = ON (5" GPS: GPS = ON)
  • Max Arming Angle 180° (Allows Turtle Mode on uneven ground)
🛠️ Guide: Oscar Liang ELRS & CRSF 📘 Docs: ExpressLRS Betaflight Config
STEP 03 // MOTORS & BI-DIR DSHOT ⚠️ PROPS OFF!

3. Bi-Directional DShot & Motor Direction Wizard

Both stacks run 32-bit / Bluejay ESC firmware supporting real-time RPM filtering. Verify Props Off before testing motor spin in the Motors tab:

  • ESC/Motor Protocol DSHOT600 (or DSHOT300 for 4K PID loop)
  • Bi-Directional DShot ON (Verify 0.00% Error Rate on bench)
  • Motor Poles Count 5" 22.6x6.5 = 14 Poles // 3" 1404 = 12 Poles
  • Motor Direction (Props Out) Motor Direction is Reversed = ON

💡 Why "Props Out" (Reversed)? Both the Vapor-X5 and Cinelog30 V3 run Props Out so front props sweep twigs and grass away from the DJI O4 Pro camera lens rather than throwing debris onto the glass. Use Betaflight's built-in Motor Direction Wizard to set each motor's spin without unsoldering wires.

🛠️ Guide: Bi-Directional DShot & RPM Filter 🛠️ Guide: Change Motor Direction in BF
STEP 04 // AUX MODES ARCHITECTURE TX15 MAX / BOXER

4. Flight Modes & Switch Assignment

Keep identical switch habits across both drones so muscle memory never fails in an emergency. Remember that ExpressLRS requires your ARM switch on AUX1 (Channel 5):

  • AUX 1 (CH5 — 2-Pos Latching SA) ARM (Range: 1700–2100)
  • AUX 2 (CH6 — 3-Pos Switch SB) Low: Acro (Air Mode) / Mid: Angle / High: GPS Rescue
  • AUX 3 (CH7 — 3-Pos Switch SC) Mid: BEEPER / High: Flip Over After Crash (Turtle)
  • AUX 4 (CH8 — 2-Pos Switch SD) PREARM (Safety Interlock) or LED_STRIP Low
🛠️ Guide: Betaflight Modes & Prearm 🛠️ Guide: Turtle Mode Setup
STEP 05 // DJI O4 PRO HD OSD CANVAS (53×20 GRID) & CLI PRESET VTX (MSP + DISPLAYPORT)

5. HD OSD Canvas Layout & Copyable Betaflight 4.5+ CLI Snippet

In the Presets tab, search for OSD for Fpv.wtf / DJI O3 / O4 (or set Video Format to HD in the OSD tab) to switch Betaflight from the narrow analog grid to the widescreen 53×20 HD Canvas. Keep the center crosshair clear and place critical telemetry in the lower peripheral vision zone:

[ CLEAR 16:9 CENTER VIEWPORT — WARNINGS & DISARM BANNER APPEAR HERE ]
📶 LQ: 2:100%   RSNR: 9dB   -64dBm 🔋 22.8V   ⚡ 3.80V/CELL   840mAh 🧭 SPD: 58 km/h   ALT: 34m (MAX 50m IL)

CHAPTER 08 // DIGITAL LINK, TUNING & LED_STRIP

Software Part 2: ELRS, O4 Pro, PIDs & LEDs

Complete the digital ecosystem: bind your RadioMaster TX15 Max / Boxer ELRS via WiFi Binding Phrase, activate and pair the DJI O4 Air Unit Pro with Goggles 3, configure Blackbox & PID presets, and program the Cinelog30 V3 dusk LEDs using Betaflight's Wiring Order Mode.

STEP 01 // EXPRESSLRS 3.X WIFI & BINDING HTTP://10.0.0.1

1. ELRS Binding Phrase & Lua Script Settings

Forget holding tiny receiver boot buttons while plugging in batteries. Set a personal Binding Phrase across your radio and both drones using the built-in ExpressLRS WiFi WebUI:

  • 1. Receiver WiFi Hotspot (60s Auto-WiFi) SSID: ExpressLRS RX // PW: expresslrs
  • 2. Set Binding Phrase in Browser Open http://10.0.0.1 → Enter UID Phrase & Save
  • 3. Radio TX WiFi (SYS → ExpressLRS Lua) WiFi Connectivity → Enable WiFi → http://10.0.0.1
  • 4. Recommended ELRS Lua Link Profile 250Hz (or 500Hz) // Telem 1:16 // Switch: Wide
  • 5. Output Power (TX15 Max / Boxer) Dynamic Power = ON // Max: 250mW–500mW

💡 Major Version Rule: Ensure both the radio TX module and receivers run the same major release (e.g., ELRS 3.x.x) and that Model Match is set to Off when first testing.

🛠️ Guide: Oscar Liang ELRS Complete Setup 📘 Docs: ExpressLRS Binding Phrase 📘 Docs: ELRS WiFi Updating
STEP 02 // DJI O4 PRO & GOGGLES 3 🌡️ USE BENCH FAN!

2. O4 Pro Activation, Pairing & Cinema Settings

Connect the DJI O4 Air Unit Pro and DJI Goggles 3 to your computer via USB-C and run DJI Assistant 2 (Consumer Drones Series) to activate and match firmware before heading to the field:

  • Hardware Linking Sequence Hold Goggles Power 5s (Beep) → Press O4 Link Pin
  • Goggles 3 Display → Canvas Mode HD (Renders full 53×20 Betaflight OSD grid)
  • Transmission Mode 1080p/100fps (60Mbps) or Race Mode (15ms)
  • Camera Recording & Color Profile 4K/60 or 4K/120 // 10-Bit D-Log M // Auto-Rec ON
  • Stabilization (RockSteady vs Gyroflow) RockSteady ON (Quick) or EIS OFF + Wide (Gyroflow)

⚠️ Thermal Protection: Keep Auto Low-Power Mode = ON so the O4 Pro stays cool while disarmed, and always point a small desk fan at the VTX during bench configuration.

🛠️ Guide: DJI O4 Air Unit Pro Setup 📘 Review & Menus: DJI Goggles 3
STEP 03 // SENSORS & GPS RESCUE ACCEL + COMPASS

3. Sensor Calibration & GPS Rescue Setup

Accurate sensors ensure level Angle mode recovery, reliable battery telemetry, and arrow-straight Betaflight 4.5+ GPS Rescue on the 5" Freestyle rig:

  • 1. Accelerometer Level Calibration Setup Tab → Place on Level Table → Calibrate Accel
  • 2. Magnetometer (5" M10 Compass) Calibrate Outdoors → Rotate 360° on All 3 Axes (30s)
  • 3. Heading / Nose Alignment Check Point Drone North → Verify Setup Model Reads ~0°
  • 4. Failsafe Tab → Stage 2 Action 5" Quad: GPS Rescue (Max Alt 45m) // 3" Whoop: Drop
  • 5. Battery Voltage Scale Check Compare OSD Voltage vs Multimeter & Calibrate
🛠️ Guide: Betaflight GPS Rescue & Compass 🛠️ Guide: Voltage & Sensor Calibration
STEP 04 // BLACKBOX, FILTERS & PIDS 16MB FLASH // 2KHZ

4. Blackbox Logging & Fleet PID Strategy

Both flight controllers include 16MB onboard Blackbox flash and ICM-42688-P gyros. Avoid over-tuning before your maiden hover—follow this verified baseline:

  • Blackbox Device & Rate Onboard Flash // 2 kHz // Debug: GYRO_SCALED
  • RPM Filter + Dynamic Notch RPM Harmonics = 3 // Dyn Notch: 3–5 (With O4 Pro)
  • 5" Vapor-X5 6S PID Baseline BF 4.5 Default or "Supafly / UAV Tech 5in Freestyle"
  • 3" Cinelog30 V3 4S PID Baseline Keep Factory GEPRC Tune (Backed up in Step 01!)
  • 30-Second Hover Motor Touch Test Hover 30s → Disarm → Motors Must Be Cool/Warm
🛠️ Guide: Oscar Liang Blackbox Analysis 🛠️ Guide: Betaflight PID & Filter Tuning 🛠️ Guide: Eliminating Propwash
STEP 05 // BETAFLIGHT LED_STRIP & WIRING ORDER MODE (CINELOG30 V3 DUSK LEDS) 20× WS2812B 5V LEDS (0..19)

5. Programming Addressable LEDs with "Wiring Order Mode"

Once you enable LED_STRIP in the Configuration tab and open the LED Strip tab, follow this 4-step workflow to map your 20 daisy-chained WS2812B LEDs (10 on the Left Duct, 10 on the Right Duct) and preview/copy the CLI configuration below:

1. CLICK "WIRING ORDER MODE"

Click the Wiring Order Mode button on the right side of the Betaflight LED Strip tab (the grid cursor turns green).

2. CLICK GRID SQUARES IN ORDER (0 → 19)

Click 20 squares on the grid matching your physical wire path: start at the LED closest to the FC solder pad (0) through the Left Duct (0–9) and across to the Right Duct (10–19).

3. EXIT WIRING MODE & ASSIGN FUNCTIONS

Turn Wiring Order Mode OFF. Drag-select LEDs 0–9 or 10–19, set Function: Color (or Arm State), check Warning: Battery, pick a color swatch, and click Save!

LIVE WIRING ORDER SIMULATOR (LEDS 0–19)
LEFT DUCT STRIP (FC LED PAD → DIN 0..9 DOUT)
RIGHT DUCT STRIP (DAISY-CHAIN → DIN 10..19 END)
Profile: Front/Left Cyan + Rear/Right Amber for high-contrast dusk orientation + automatic Red flash on low 4S battery.
